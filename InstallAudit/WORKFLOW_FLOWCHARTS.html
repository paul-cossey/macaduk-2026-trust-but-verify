📊 Summary

These flowcharts document the complete workflow architecture of the AutoUpdateTester system. The system supports two primary installation methods:

Manual Installation

  • User-driven installation process
  • Real-time security monitoring
  • Interactive profile generation
  • Manual cleanup required

Munki Local Installation

  • Automated installation via Munki
  • System state comparison
  • Automatic profile detection
  • Automated cleanup

Key Features Across All Workflows

  • Configuration Profile Generation - PPPC, Notifications, System Extensions, etc.
  • Extension Attribute Generation - Version tracking scripts
  • Security Monitoring - Real-time event tracking
  • System State Comparison - Before/after analysis
  • Smart De-duplication - Prevents duplicate profiles
  • Team Consolidation - Groups related apps by Team ID
  • Interactive Menus - User-friendly selection interfaces
  • Comprehensive Reporting - Detailed markdown reports
